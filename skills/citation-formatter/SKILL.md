# Citation Formatter

Format guide for in-text citations and reference lists in the three major styles.

## When to use
- Formatting citations in academic papers
- Creating reference lists in APA 7th, IEEE, or Vancouver style
- Need to generate PDF/DOCX output with proper academic formatting
- After using academic-source-search to collect sources

## When NOT to use
- Searching for academic sources (use `academic-source-search`)
- Writing non-academic content (blog posts, documentation)
- Need mathematical notation rules only (use `math-notation`)
- User wants to cite in a style not covered (APA/IEEE/Vancouver only)

## APA 7th Edition

### Document configuration
| Element | Value |
|---------|-------|
| Font | Times New Roman 12pt |
| Line spacing | Double (2.0) |
| Margins | 2.54 cm (1 in) on all sides |
| Alignment | Left (not justified) |
| First line indent | 1.27 cm (0.5 in) per paragraph |
| Page numbering | Top right (cover = page 1, body starts at page 2) |
| References | Hanging indent (1.27 cm), alphabetical order |

### Table of Contents — APA 7th (Optional)
The table of contents is optional in APA 7th. It is placed between the cover page and the abstract.

**Format:**
| Element | Value |
|---------|-------|
| Title | "Table of Contents" centered, bold, 12pt |
| Line spacing | Double (2.0) |
| Level 1 (##) | Left-aligned, optional bold |
| Level 2 (###) | Indent 1.27 cm (0.5 in) |
| Level 3 (####) | Indent 2.54 cm (1 in) |
| Separation | Dot leader (......) between entry and page number |
| Page numbers | Right-aligned |

**Visual example:**
```
Table of Contents

Abstract ................................................. 2
1. Introduction .......................................... 3
     1.1. Background ..................................... 3
     1.2. Problem ........................................ 4
2. Theoretical Framework .................................. 5
     2.1. Concept A ...................................... 5
     2.2. Concept B ...................................... 7
References .............................................. 10
```

**Important:** The TOC is automatically generated by the script from headings. Do not write it manually in Markdown. Activate with `TOC: "true"` in the frontmatter.

### Title Page — APA 7th Student Paper
The title page is MANDATORY in APA 7th and must occupy the entire page 1:

```
+------------------------------------------+
|                                    [p. 1]|
|                                            |
|                                            |
|           Paper Title                     |
|           (bold, centered,                |
|           approximately in the            |
|           upper third)                    |
|                                            |
|           Author Name                     |
|                                            |
|           Institution Name                |
|                                            |
|           Program/                         |
|           Specialization                   |
|                                            |
|           Course Name                      |
|                                            |
|           Professor Name                  |
|           (with academic title)           |
|                                            |
|           Due Date                        |
|                                            |
|                                            |
+------------------------------------------+
```

**APA 7th title page rules:**
- Everything in Times New Roman 12pt, double spacing
- Title in bold, horizontally centered, approximately in the upper third
- No "Running head" (APA 7th removed the running head for student papers)
- No bold in other elements (only the title)
- Page numbering: "1" in the top right corner
- Page 2 begins with: paper title (centered, bold) followed by text
- **NEVER fabricate title page data. Always ask the user for each field.**
- **Elements must be distributed with EQUAL spacing to fill the entire page.**

**Equal spacing implementation on the title page:**

Vertical spacing is automatically implemented via `generate_outputs.py`
but requires CSS and DOCX to use the correct configuration:

**CSS (PDF via WeasyPrint):**
```css
.title-page {
  display: flex;
  flex-direction: column;
  justify-content: space-evenly;
  align-items: center;
  height: 9in;  /* 11in - 2x1in margins */
}
```

**DOCX (python-docx):**
Each title page element should have `space_before=72` and `space_after=0`,
and the last element should have `space_after=72`. This distributes 7 equal
gaps (~72pt = 1in) between and around 6 elements.

The code in `generate_outputs.py` already implements this for APA 7th.
When adding new fields to the title page (e.g., DATE), ensure they
also receive `space_before=72`.

**YAML frontmatter fields for the title page:**
```yaml
TITLE: "Full paper title"
AUTHOR: "Full author name"
INSTITUTION: "Institution name"
PROGRAM: "Program/specialization name"
COURSE: "Course name"
PROFESSOR: "Professor name (with title)"
DATE: "Due date"
TOC: "true"
NORM: "APA 7th"
```

### In-text citations
```
(Author, Year, p. X)                        → parenthetical
Author (Year) states that...                → narrative
(Author, Year, pp. X-X)                     → page range
(Author & Author, Year)                     → 2 authors (use &)
(Author et al., Year)                       → 3+ authors
("Short Title", Year)                       → no author
```

### References
```
Journal article:
  Author, A. A., & Author, B. B. (Year). Title. Journal Name, volume(issue), pages. https://doi.org/XXXX

Book:
  Author, A. A. (Year). Title (ed.). Publisher. https://doi.org/XXXX

Book chapter:
  Author, A. A. (Year). Chapter title. In Editor (Ed.), Book title (pp. X-X). Publisher.

Conference:
  Author, A. A. (Year). Title. Proceedings of Conference Name, pages. https://doi.org/XXXX

Thesis:
  Author, A. A. (Year). Title [Doctoral dissertation, University]. Repository. URL

Website:
  Author. (Year). Title. Site. URL

Preprint:
  Author. (Year). Title. arXiv. https://arxiv.org/abs/XXXX
```

### APA Examples
```
In-text:
  Artificial intelligence has transformed education (Smith, 2020, p. 45)
  [Paraphrased citation]

  "Deep learning requires large volumes of labeled data"
  (Johnson & Williams, 2021, p. 12) [Direct quote]

Reference:
  Smith, R. (2020). Artificial intelligence in education. Journal of Innovation, 15(2), 40-55. https://doi.org/10.xxxx/xxxxx
```

## IEEE

### Document configuration
| Element | Value |
|---------|-------|
| Font | Times New Roman 10pt |
| Line spacing | Single (1.0), double between sections |
| Margins | 2.54 cm (1 in) on all sides |
| Columns | 2 for main text |
| Title | Centered, 24pt, bold |
| Section headings | 10pt, uppercase |
| Page numbering | Bottom centered |
| References | Numbered [1], [2]... in order of appearance |

### In-text citations
```
As demonstrated in [1]...                   → general reference
"...quoted text..." [2, p. 5]              → with page
Several studies [3], [4], [5] confirm...   → multiple
As mentioned in [1, pp. 10-15]...          → page range
```

### References
```
Journal article:
  [1] A. A. Author and B. B. Author, "Title," Journal Name, vol. X, no. Y, pp. Z-Z, Year. doi: XXXX.

Book:
  [2] A. A. Author, Title (ed.). Publisher, Year.

Conference:
  [3] A. A. Author, "Title," in Proc. Conference Abbreviation, Year, pp. X-X.

Technical report:
  [4] A. A. Author, "Title," Institution, Tech. Rep. X, Year.

Standard:
  [5] Standard Name, Standard ID, Year. [Online]. Available: URL

Website:
  [6] A. A. Author, "Title," Site, Year. [Online]. Available: URL
```

### IEEE Examples
```
In-text:
  The proposed method improves accuracy by 15% [1, p. 234]
  [Paraphrased citation]

  "Genetic algorithms enable optimization of nonlinear functions"
  [2, p. 89] [Direct quote]

Reference:
  [1] M. Rodriguez and P. Sanchez, "Deep learning for medical imaging,"
  IEEE Trans. Med. Imaging, vol. 41, no. 5, pp. 1123-1135, 2024,
  doi: 10.1109/TMI.2024.1234567.
```

## Vancouver

### Document configuration
| Element | Value |
|---------|-------|
| Font | Times New Roman 12pt |
| Line spacing | Double (2.0) |
| Margins | 2.54 cm (1 in) on all sides |
| Alignment | Left |
| Page numbering | Top right |
| References | Numbered in order of appearance |

### In-text citations
```
According to previous studies (1,2)...      → (number)
"...direct quote..." (3).                   → at end
Several authors (4-6) agree...             → range
```

### References
```
Journal article:
  1. Author AA, Author BB. Title. Abbreviated Journal Name. Year;Volume(Issue):Pages. doi:XXXX

Book:
  2. Author AA. Title. Edition. Place: Publisher; Year.

Book chapter:
  3. Author AA. Chapter title. In: Editor AA, editor. Book title. Place: Publisher; Year. p. X-X.

Conference:
  4. Author AA. Title. In: Proceedings of Conference Name; Date; Location. Place: Publisher; Year. p. X-X.

Thesis:
  5. Author AA. Title [dissertation]. Place: University; Year.

Website:
  6. Author AA. Title [Internet]. Place: Publisher; Year [cited YYYY MMM DD]. Available from: URL
```

### Vancouver Examples
```
In-text:
  The prevalence of type 2 diabetes increases globally (1,2) [Paraphrased citation]

  "Physical activity reduces cardiovascular risk by 30%"
  (3, p. 45) [Direct quote]

Reference:
  1. Martinez L, Gomez R. Epidemiology of diabetes in Latin America.
  Rev Salud Publica. 2023;45(2):123-35. doi:10.xxxx/xxxxx
```

## General Rules Comparison

| Element | APA 7th | IEEE | Vancouver |
|---------|---------|------|-----------|
| Reference order | Alphabetical by author | Order of appearance [1], [2]... | Order of appearance (1), (2)... |
| Link in reference | DOI/URL | DOI/URL | DOI/URL |
| Author format | Last, Initial. | Initial. Last | Last Initial |
| & vs "and" | & in parentheses, "and" in text | N/A | N/A |
| Title emphasis | Italic for book/journal | Quotes in article | Italic for book/journal |
| Volume | Italic | Bold | No special formatting |
| DOI | https://doi.org/XXXX | doi: XXXX | doi:XXXX |

## Error handling
- **Style not recognized:** Show the 3 supported styles (APA, IEEE, Vancouver) and ask for selection
- **Title page data incomplete:** Ask for each missing field, never fabricate
- **DOI does not resolve:** Search in CrossRef or Google Scholar
- **generate_outputs.py not found:** Look in citation-formatter/scripts/
- **Mixed styles detected:** Alert and correct to the selected style

## File structure
```
citation-formatter/
├── SKILL.md

    └── generate_outputs.py
```

## Restrictions
- Do not mix formats from different styles in the same document
- Do not omit the DOI when available
- Do not use "Retrieved from" in APA 7th (use URL/DOI directly)
- Do not include references without a verifiable active link
- Do not fabricate title page data — always ask the user
- Do not use asterisks for italic in content processed by generate_outputs.py — use `_text_` per math-notation
