# Citation Formatter

Format guide for in-text citations and reference lists in the three major styles.

## When to use
- Formatting citations in academic papers
- Creating reference lists in APA 7th, IEEE, or Vancouver style
- Need to generate PDF/DOCX output with proper academic formatting
- After using academic-source-search to collect sources
- **Keywords:** "APA", "APA 7", "APA 7th", "IEEE", "Vancouver", "citation", "citations", "reference", "references", "academic format", "bibliography", "bibliografia", "formato academico", "citar", "referencias APA", "format paper", "in-text citation", "reference list", "hang indent", "title page", "generate PDF", "generate DOCX", "academic writing", "paper format", "formatted references", "formatting style", "citation style", "normas APA", "normas IEEE", "estilo Vancouver"

## First step — confirm style and target
Before formatting anything, confirm **two things** with the user (1 scoping round):
1. **Citation style**: APA 7th, IEEE, or Vancouver.
2. **Output target**: reference list only, a full PDF (HTML), or a DOCX.

This avoids formatting the whole document in the wrong style and redoing it.
For anything non-APA, note that the scripted **title page is APA-7th only** —
if the user needs a non-APA document, produce the body/references in that style
and skip the APA title page.

## When NOT to use
- Searching for academic sources (use `academic-source-search`)
- Writing non-academic content (blog posts, documentation)
- Need mathematical notation rules only (use `math-notation`)
- User wants to cite in a style not covered (APA/IEEE/Vancouver only)

## APA 7th Edition

### Document configuration
| Element | Value |
|---------|-------|
| Font | Times New Roman 12pt |
| Line spacing | Double (2.0) |
| Margins | 2.54 cm (1 in) on all sides |
| Alignment | Left (not justified) |
| First line indent | 1.27 cm (0.5 in) per paragraph |
| Page numbering | Top right (cover = page 1, body starts at page 2) |
| References | Hanging indent (1.27 cm), alphabetical order |

### Table of Contents — APA 7th (Optional)
The table of contents is optional in APA 7th. It is placed between the cover page and the abstract.

**Format:**
| Element | Value |
|---------|-------|
| Title | "Table of Contents" centered, bold, 12pt |
| Line spacing | Double (2.0) |
| Level 1 (##) | Left-aligned, optional bold |
| Level 2 (###) | Indent 1.27 cm (0.5 in) |
| Level 3 (####) | Indent 2.54 cm (1 in) |
| Separation | Dot leader (......) between entry and page number |
| Page numbers | Right-aligned |

**Visual example:**
```
Table of Contents

Abstract ................................................. 2
1. Introduction .......................................... 3
     1.1. Background ..................................... 3
     1.2. Problem ........................................ 4
2. Theoretical Framework .................................. 5
     2.1. Concept A ...................................... 5
     2.2. Concept B ...................................... 7
References .............................................. 10
```

**Important:** The TOC is automatically generated by the script from headings. Do not write it manually in Markdown. Activate with `TOC: "true"` in the frontmatter.

### Title Page — APA 7th Student Paper (APA only)
The title page is MANDATORY in APA 7th and must occupy the entire page 1.
**The scripted title page generator is APA-7th specific** — for IEEE/Vancouver
documents, do not emit an APA title page; produce the body and references in the
selected style instead.

```
+------------------------------------------+
|                                    [p. 1]|
|                                            |
|                                            |
|           Paper Title                     |
|           (bold, centered,                |
|           approximately in the            |
|           upper third)                    |
|                                            |
|           Author Name                     |
|                                            |
|           Institution Name                |
|                                            |
|           Program/                         |
|           Specialization                   |
|                                            |
|           Course Name                      |
|                                            |
|           Professor Name                  |
|           (with academic title)           |
|                                            |
|           Due Date                        |
|                                            |
|                                            |
+------------------------------------------+
```

**APA 7th title page rules:**
- Everything in Times New Roman 12pt, double spacing
- Title in bold, horizontally centered, approximately in the upper third
- No "Running head" (APA 7th removed the running head for student papers)
- No bold in other elements (only the title)
- Page numbering: "1" in the top right corner
- Page 2 begins with: paper title (centered, bold) followed by text
- **NEVER fabricate title page data. Always ask the user for each field.**
- **Elements must be distributed with EQUAL spacing to fill the entire page.**

**Equal spacing implementation on the title page:**

Vertical spacing is automatically implemented via `generate_outputs.py`
for DOCX and PDF (reportlab):

**PDF (reportlab):**
Each title page element is separated by a `Spacer(1, 0.55 * inch)` gap.
The title uses `Times-Bold` at 1.2x font size; the remaining elements use
`Times-Roman`. This distributes the available space evenly across the page.

**DOCX (python-docx):**
Each title page element should have `space_before=72` and `space_after=0`,
and the last element should have `space_after=72`. This distributes 7 equal
gaps (~72pt = 1in) between and around 6 elements.

The code in `generate_outputs.py` already implements this for APA 7th.
When adding new fields to the title page (e.g., DATE), ensure they
also receive `space_before=72`.

**YAML frontmatter fields for the title page:**
```yaml
TITLE: "Full paper title"
AUTHOR: "Full author name"
INSTITUTION: "Institution name"
PROGRAM: "Program/specialization name"
COURSE: "Course name"
PROFESSOR: "Professor name (with title)"
DATE: "Due date"
TOC: "true"
NORM: "APA 7th"
```

### In-text citations
```
(Author, Year, p. X)                        → parenthetical
Author (Year) states that...                → narrative
(Author, Year, pp. X-X)                     → page range
(Author & Author, Year)                     → 2 authors (use &)
(Author et al., Year)                       → 3+ authors
("Short Title", Year)                       → no author
```

### References
Use `_text_` for italics (per math-notation) — never `*text*` in content processed
by generate_outputs.py.

```
Journal article:
  Author, A. A., & Author, B. B. (Year). Title. _Journal Name_, volume(issue), pages. https://doi.org/XXXX

Book:
  Author, A. A. (Year). _Title_ (ed.). Publisher. https://doi.org/XXXX

Book chapter:
  Author, A. A. (Year). Chapter title. In Editor (Ed.), _Book title_ (pp. X-X). Publisher.

Conference:
  Author, A. A. (Year). Title. _Proceedings of Conference Name_, pages. https://doi.org/XXXX

Thesis:
  Author, A. A. (Year). _Title_ [Doctoral dissertation, University]. Repository. URL

Website:
  Author. (Year). _Title_. Site. URL

Preprint:
  Author. (Year). _Title_. arXiv. https://arxiv.org/abs/XXXX
```

### APA Examples
```
In-text:
  Artificial intelligence has transformed education (Smith, 2020, p. 45)
  [Paraphrased citation]

  "Deep learning requires large volumes of labeled data"
  (Johnson & Williams, 2021, p. 12) [Direct quote]

Reference:
  Smith, R. (2020). Artificial intelligence in education. _Journal of Innovation_, 15(2), 40-55. https://doi.org/10.xxxx/xxxxx
```

## IEEE

### Document configuration
| Element | Value |
|---------|-------|
| Font | Times New Roman 10pt |
| Line spacing | Single (1.0), double between sections |
| Margins | 2.54 cm (1 in) on all sides |
| Columns | 2 for main text |
| Title | Centered, 24pt, bold |
| Section headings | 10pt, uppercase |
| Page numbering | Bottom centered |
| References | Numbered [1], [2]... in order of appearance |

### In-text citations
```
As demonstrated in [1]...                   → general reference
"...quoted text..." [2, p. 5]              → with page
Several studies [3], [4], [5] confirm...   → multiple
As mentioned in [1, pp. 10-15]...          → page range
```

### Reference Examples
```
Journal article:
  [1] A. A. Author and B. B. Author, "Title," _Journal Name_, vol. X, no. Y, pp. Z-Z, Year. doi: XXXX.

Book:
  [2] A. A. Author, _Title_ (ed.). Publisher, Year.

Conference:
  [3] A. A. Author, "Title," in Proc. Conference Abbreviation, Year, pp. X-X.

Technical report:
  [4] A. A. Author, "Title," Institution, Tech. Rep. X, Year.

Standard:
  [5] Standard Name, Standard ID, Year. [Online]. Available: URL

Website:
  [6] A. A. Author, "Title," _Site_, Year. [Online]. Available: URL
```

### IEEE Examples
```
In-text:
  The proposed method improves accuracy by 15% [1, p. 234]
  [Paraphrased citation]

  "Genetic algorithms enable optimization of nonlinear functions"
  [2, p. 89] [Direct quote]

Reference:
  [1] M. Rodriguez and P. Sanchez, "Deep learning for medical imaging,"
  _IEEE Trans. Med. Imaging_, vol. 41, no. 5, pp. 1123-1135, 2024,
  doi: 10.1109/TMI.2024.1234567.
```

## Vancouver

### Document configuration
| Element | Value |
|---------|-------|
| Font | Times New Roman 12pt |
| Line spacing | Double (2.0) |
| Margins | 2.54 cm (1 in) on all sides |
| Alignment | Left |
| Page numbering | Top right |
| References | Numbered in order of appearance |

### In-text citations
```
According to previous studies (1,2)...      → (number)
"...direct quote..." (3).                   → at end
Several authors (4-6) agree...             → range
```

### Reference Examples
```
Journal article:
  1. Author AA, Author BB. Title. _Abbreviated Journal Name_. Year;Volume(Issue):Pages. doi:XXXX

Book:
  2. Author AA. _Title_. Edition. Place: Publisher; Year.

Book chapter:
  3. Author AA. Chapter title. In: Editor AA, editor. _Book title_. Place: Publisher; Year. p. X-X.

Conference:
  4. Author AA. Title. In: Proceedings of Conference Name; Date; Location. Place: Publisher; Year. p. X-X.

Thesis:
  5. Author AA. _Title_ [dissertation]. Place: University; Year.

Website:
  6. Author AA. _Title_ [Internet]. Place: Publisher; Year [cited YYYY MMM DD]. Available from: URL
```

### Vancouver Examples
```
In-text:
  The prevalence of type 2 diabetes increases globally (1,2) [Paraphrased citation]

  "Physical activity reduces cardiovascular risk by 30%"
  (3, p. 45) [Direct quote]

Reference:
  1. Martinez L, Gomez R. Epidemiology of diabetes in Latin America.
  _Rev Salud Publica_. 2023;45(2):123-35. doi:10.xxxx/xxxxx
```

## General Rules Comparison

| Element | APA 7th | IEEE | Vancouver |
|---------|---------|------|-----------|
| Reference order | Alphabetical by author | Order of appearance [1], [2]... | Order of appearance (1), (2)... |
| Link in reference | DOI/URL | DOI/URL | DOI/URL |
| Author format | Last, Initial. | Initial. Last | Last Initial |
| & vs "and" | & in parentheses, "and" in text | N/A | N/A |
| Title emphasis | Italic for book/journal | Quotes in article | Italic for book/journal |
| Volume | Italic | Bold | No special formatting |
| DOI | https://doi.org/XXXX | doi: XXXX | doi:XXXX |

## Scripts

| Script | Args | Description |
|--------|------|-------------|
| `scripts/references.py` | `--file F --norm N [--sort S] [--out O] [--pairs]` | Formats a `sources.yaml` file (from `academic-source-search`) into a reference list (APA 7th / IEEE / Vancouver) using math-notation italics (`_text_`). `--pairs` prints in-text citation snippets; `--sort alpha` (default for APA) or `--order` (default for IEEE/Vancouver). Exits 1 on schema errors (missing `title`). |
| `scripts/generate_outputs.py` | `--file F --html/--docx/--pdf [--out O]` | Full document generator: APA title page, optional TOC (frontmatter `TOC: "true"`), and body with inline math (italics/bold/sub/sup). `--html` → styled HTML; `--docx` → DOCX (python-docx, inline runs + Word TOC field); `--pdf` → real PDF via reportlab (title page, dot-leader TOC with page numbers, 1- or 2-column layout by norm). No args → inline-parser self-test. |

CLI examples:
```bash
# Reference list from academic-source-search sources.yaml (APA 7th, alphabetical)
python scripts/references.py --file sources.yaml --norm "APA 7th" --out references.md
# IEEE numbered references + in-text pairs
python scripts/references.py --file sources.yaml --norm IEEE --pairs
# Full HTML document (APA 7th title page + TOC + body)
python scripts/generate_outputs.py --file paper.md --html --out paper.html
# Real PDF
python scripts/generate_outputs.py --file paper.md --pdf --out paper.pdf
# DOCX (inline math runs + TOC field)
python scripts/generate_outputs.py --file paper.md --docx --out paper.docx
```

Note: `--norm` is accepted for compatibility but the title-page branch is
selected by the `NORM:` frontmatter value (only `"APA 7th"` gets a title page);
TOC is written when the frontmatter key `TOC: "true"` is present.

## Output format
- In-text citations formatted according to the selected style
- Reference list with correct formatting (via `references.py` or embedded in the generated document)
- Optional: APA 7th title page (APA docs only), TOC with dot leaders/page numbers, and a real PDF (`--pdf`) or DOCX (`--docx`) via generate_outputs.py

## Error handling
- **Style not recognized:** Show the 3 supported styles (APA, IEEE, Vancouver) and ask for selection
- **Title page data incomplete:** Ask for each missing field, never fabricate
- **DOI does not resolve:** Search in CrossRef or Google Scholar
- **generate_outputs.py not found:** Look in citation-formatter/scripts/
- **Frontmatter value contains `:`:** The bundled parser splits on the first `:` per line, so a value like `TITLE: "Exam: Math"` works; avoid quoting or multi-`:` forms needing full YAML — if you need richer YAML, `import yaml; yaml.safe_load(...)`
- **DOCX requested but python-docx missing:** the script errors with install instructions; fall back to `--pdf` instead
- **PDF requested but reportlab missing:** the script errors with install instructions; fall back to `--html` → print instead
- **Mixed styles detected:** Alert and correct to the selected style

## Restrictions
- Do not mix formats from different styles in the same document
- Do not omit the DOI when available
- Do not use "Retrieved from" in APA 7th (use URL/DOI directly)
- Do not include references without a verifiable active link
- Do not fabricate title page data — always ask the user
- Do not use asterisks for italic in content processed by generate_outputs.py — use `_text_` per math-notation
- Do not emit an APA title page for IEEE/Vancouver documents — the title page generator is APA-7th specific
