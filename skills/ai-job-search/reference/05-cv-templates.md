# CV Templates and Tailoring Guide

## Key Principles

- **Hard 2-page limit** — must fit exactly 2 pages
- **Profile statement** — 3-4 line elevator pitch tailored per role
- **Relevance-weighted cutting** — score each line by relevance, uniqueness, narrative load
- **ATS verification** — check PDF text layer for parseability
- **Compile-and-inspect loop** — always compile and visually check the PDF

## Section Order (Technical Roles)
1. Profile statement
2. Core competencies / Skills
3. Professional Experience (reverse chronological)
4. Education
5. Languages
6. Publications & Awards
7. References

## Tailoring Rules

### Profile Statement
- 3-4 lines, concise elevator pitch
- Focus on what employer gains
- For domain changers, lead with transfer argument

### Skills Section
- 5-7 key competencies, tailored to role
- Use posting's own terms for ATS matching

### Experience
- 4-6 bullets most recent, 2-3 previous, 2 older
- Emphasize measurable results
- Check tenure against visible output

## Relevance-Weighted Cutting

Score each line on:
1. Relevance to posting
2. Uniqueness in document
3. Narrative load (does cover letter depend on it?)

Cut lowest total score first, regardless of section.
