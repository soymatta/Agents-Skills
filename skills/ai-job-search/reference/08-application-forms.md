# Application Form Fields

Many applications need free-text fields typed directly into portals.

## Rules

- Every claim must be defensible from existing profile/CV sources
- No new claims, no inflated scope
- Count words/characters programmatically

## Field Types

### Self-Introduction (100-200 words)
1. Current status
2. Strongest evidence with numbers
3. Trajectory line
4. What you want next + employer connection

### Hard Character Limits
1. Pick most distinctive true thing (number, unusual combo, problem shape)
2. Draft 4-6 candidates
3. Count characters programmatically
4. Present with counts, recommend one

### Structured Project Entries
- Descriptive project name (not employer name)
- Role on that project (not upgraded)
- Dates for that project (not employment dates)
- 100-150 word description + ~60 word short version
