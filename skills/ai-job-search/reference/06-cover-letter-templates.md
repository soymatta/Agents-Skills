# Cover Letter Templates

## Key Rules

- **Hard 1-page limit** — never exceed
- **250-300 words** body text maximum
- **No em-dashes, no cliches**
- **Forward-looking** — focus on tasks you'll solve

## Structure

### Opening
- Role + connection to background (2-3 sentences)

### Body
- Most relevant experience
- Bullet list of concrete achievements (3-5)

### Motivation
- Why this company specifically
- Reference mission/values

### Closing
- Brief, confident, forward-looking

## Tailoring

- Match language to posting
- Use named contact if available
- Reference conversation if you called
- Company name correct throughout

## Checklist
- [ ] No em-dashes
- [ ] No cliches
- [ ] Every claim backed by example
- [ ] Forward-looking framing
- [ ] Company-specific content
- [ ] Fits on one page
- [ ] Language matches posting
